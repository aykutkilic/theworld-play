# The World — play

A caricature globe you can scrub from the Cambrian to this very second: drifting continents, prehistoric
life, empires, rulers, people, wars and battles, wonders, inventions, trade, voyages, weather and the sky.

**Play:** https://aykutkilic.github.io/theworld-play/

This repository only holds the built site.

## Data & attribution

- Plate tectonics: Merdith et al. (2021), EarthByte/GPlates plate model — CC BY 4.0.
- Historical borders: [historical-basemaps](https://github.com/aourednik/historical-basemaps) by André Ourednik — GPL-3.0.
- People, rulers, battles, films, sports, landmarks, statues, dams, administrative units, governors: [Wikidata](https://www.wikidata.org) — CC0.
- Coastlines, lakes, rivers, provinces: [Natural Earth](https://www.naturalearthdata.com) — public domain.
- Some lakes and the high-voltage grid: © [OpenStreetMap](https://www.openstreetmap.org/copyright) contributors — ODbL.
- Terrain: [AWS Terrain Tiles](https://registry.opendata.aws/terrain-tiles/) (Mapzen/Tilezen; SRTM, GMTED, ETOPO and others).
- Weather: [Open-Meteo](https://open-meteo.com) (ERA5 reanalysis, Copernicus) — CC BY 4.0, non-commercial use.
- Climate normals: NOAA PSL NCEP/NCAR Reanalysis; temperature series: HadCRUT5 (Met Office, OGL).
- Earthquakes, eruptions, tsunamis: NOAA NCEI; tropical cyclones: NOAA IBTrACS.
- Stars: [HYG Database](https://github.com/astronexus/HYG-Database) by David Nash — CC BY-SA 4.0; constellation figures: d3-celestial (Olaf Frohn, BSD-3-Clause, after Stellarium); planets: astronomy-engine (MIT).
- Article summaries are fetched live from Wikipedia (CC BY-SA).

Curated datasets (wonders, creatures, wars and campaigns, battle timelines, trade routes, movements, voyages)
were compiled for this project from standard histories; dates, numbers and positions are approximate.
